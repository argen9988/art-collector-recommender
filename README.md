# 藏家推薦系統（art-collector-recommender）：雲端資安治理、費用精算與 AI 自動化驗收懶人包

提供「藏家推薦系統」在 Google AI Studio ＋ Cloud Run ＋ Cloud SQL 架構下的完整資安評估報告、六大設定規範 SOP、每月雲端費用精算器，以及**專為無資訊背景使用者設計、可交由任何 AI Agent 全程代操電腦完成**的 **Lazy Pack（懶人包）**。

---

## 🚀 一、 最無腦用法（完全不需資訊背景，交給任何 AI 代操電腦）

您不需要懂任何程式或終端機指令！只要打開您電腦上的任何一款 AI 工具（**Claude Code、ChatGPT 桌面版／Codex、Antigravity 2、Cursor、OpenCode**），把本專案的 **[`AGENT_SETUP_雲端資安設定與驗收指南.md`](./AGENT_SETUP_雲端資安設定與驗收指南.md)**（或下方 GitHub Raw 網址）貼給 AI，對它說一句話即可：

> **「請讀這份指南，幫我執行藏家推薦系統的資安設定與檢查！」**
> `https://raw.githubusercontent.com/argen9988/art-collector-recommender/master/AGENT_SETUP_雲端資安設定與驗收指南.md`

## 📖 二、 三階段與 10 個細項一覽（不押日期、每項皆附 6 點白話說明卡）

進入任何階段時，AI 與腳本都會**先自動做唯讀檢查**（已設好的直接標記 `✅ 已存在，自動跳過`）；針對還沒設定的細項，**每一細項都會先展示「6 點白話說明卡」（這是做什麼、為什麼要做、有什麼好處、費用與數值影響、會不會把系統弄壞、誰來按）**，並讓您自由決定「現在做」或「先跳過」：

### 🔹 第一階段：立即止血與基礎防護（共 3 項）
1. **【細項 1-1】切換 Google 付費層（Paid Tier 綁定帳單）**：
   - **為什麼要做**：Google 免費版（Free Tier）條款明定會將輸入的藏家姓名、電話與畫作底價拿去訓練 AI 並供人工審閱！切換為 Paid Tier 後，即享 **100% 零資料訓練與禁止人工審閱**保障。
2. **【細項 1-2】設定「雙管理員（Owner）」帳號共管**：
   - **為什麼要做**：加入「部門公務 Gmail」或「主管 Gmail」共同擔任最高管理員（共 2 人以上），避免單一開發者休假或離職造成沒人進得去的維運孤島（**NT$0 免費**）。
3. **【細項 1-3】設定「每月預算提醒鈴」＋「AI 每日呼叫保險絲」＋「同仁 Gmail 登入白名單」（含互動問答題）**：
   - **互動問答 A｜每月預算警示金額（預設原值：`NT$1,000` / 月）**：屬於「軟止損（記帳提醒鈴）」，當月花費達 50%、80%、100% 自動寄信通知，**不會把網站斷電關機**。
   - **互動問答 B｜AI 每日呼叫次數硬上限（預設原值：`1,000` 次 / 日）**：屬於「硬止損（防刷爆保險絲）」，呼叫 1,000 次一天僅約 NT$3～10 元；一旦當天達上限即自動擋下新 AI 請求（隔天恢復），就算程式寫錯陷入無窮迴圈也**絕對刷不爆信用卡**。
   - **同仁 Gmail 登入白名單**：於 OAuth `Testing` 模式加入部門同仁 `@gmail.com`，名單外的外人連登入畫面都進不去（直接攔截回傳 `403`）。

### 🔹 第二階段：系統架構加固與規格選型（3 項核心 ＋ 2 項非必要選配）
4. **【細項 2-1】把 API 金鑰與資料庫密碼收進雲端保險箱（Secret Manager）**：
   - 防止外人按瀏覽器 `F12` 偷走 `GEMINI_API_KEY` 或資料庫密碼（每月前 6 組免費 **NT$0**，由 AI 自動建立）。
5. **【細項 2-2】關閉資料庫（Cloud SQL）對外公網大門、開啟 SSL 加密與每日自動備份**：
   - 關閉公網 IP 防駭客暴力猜密碼，並設定每天凌晨 3 點自動備份（保留 14 天），誤刪資料也能隨時救回。
6. **【細項 2-3】互動選擇資料庫月租方案（6 選 1 選單，含 NT$500–600/月 甜蜜點方案）**：
   - 依部門預算選出最適合的資料庫規格，由 AI 自動切換（詳見下方第三節對照表）。
7. **【細項 2-4（🟢 非必要選配 1）】是否啟用企業級 Vertex AI**：
   - 留在 AI Studio Paid Tier 已享 100% 資料不訓練保障且維持一鍵部署便利性，**預設建議跳過**；未來若需指定台灣彰濱機房與免金鑰再開啟。
8. **【細項 2-5（🟢 非必要選配 2）】是否啟用「排程自動發送客製化 EDM」定時器（Cloud Scheduler）**：
   - 若目前由業務手動查詢或按鈕寄信，**預設建議跳過**；若需定時自動跑「以人推畫／以畫推人」發信再開啟（前 3 個排程免費 **NT$0**）。

### 🔹 第三階段：上線前原始碼與 AI 總體檢（共 2 項）
9. **【細項 3-1】本機原始碼金鑰外洩自動掃描（SAST）**：
   - AI 自動翻遍所有網站程式碼，確認 0 硬編碼金鑰、0 `NEXT_PUBLIC_` 機密外洩（只讀不改、**NT$0**）。
10. **【細項 3-2】20 題 AI 推薦準確度與「防惡意套話（Prompt Injection）」紅隊壓力測試**：
    - 以 **100% 虛構假資料**自動考 20 題（10 題考推薦畫作不超預算、零幻覺、不把其他藏家放進 EDM `CC` 欄位；10 題考拒絕駭客套話指令），100% 通過才算合格。

## 📄 四、 雙軌報告自動輸出（單次階段報告 ＋ 全部執行累計總報告）

每次執行完任一階段或費用精算，腳本都會自動在專案的 `reports/` 資料夾產出兩份 Markdown 報告，方便您直接回報資訊部：

1. **單次階段執行成果報告**：`reports/stage-<1|2|3|cost>-report-<YYYYMMDD-HHMMSS>.md`
   - 完整記錄當次跑了哪個階段、每一細項是 `✅ 已符合`、`🔧 本次已完成` 或 `⏭️ 本次暫緩跳過`，以及當次費用精算。
2. **全部階段執行累計總報告**：`reports/full-execution-report.md`
   - 自動把第一階段、第二階段、第三階段的最新完成狀態與「💰 雲端服務開啟清單與每月費用精算總表」整併在同一份總表裡，隨時保持最新全貌。

## 🛠️ 五、 進階：手動執行指令參考（由 AI 自動代跑，人類無須背誦）

```bash
# 於 GCP Cloud Shell（或已安裝 gcloud 之電腦）執行：
bash lazy-pack/gcp-setup-and-check.sh                # 開啟互動選單（可選第 1 階段、第 2 階段、費用精算或全部）
bash lazy-pack/gcp-setup-and-check.sh --stage 1      # 只跑第一階段（立即止血與基礎防護）
bash lazy-pack/gcp-setup-and-check.sh --stage 2      # 只跑第二階段（系統架構加固與規格選型）
bash lazy-pack/gcp-setup-and-check.sh --stage cost   # 只跑雲端服務開啟清單與每月費用精算表
bash lazy-pack/gcp-setup-and-check.sh --item 3       # 只挑單一細項（例如第 3 項預算與配額問答）執行
# --item 編號對照：1 Paid Tier 計費綁定、2 雙 Owner 共管、3 預算／API 上限／Gmail 白名單、4 Secret Manager 金鑰隔離、
#                 5 Cloud SQL 網路防護、6 Cloud SQL 規格月租選單、7 Vertex AI 選配、8 排程 EDM 選配（第三階段沒有 --item，用下面的 --scan-only／--eval-only）
bash lazy-pack/gcp-setup-and-check.sh --check-only   # 純唯讀體檢模式（只檢查與出報告，不修改設定）
bash lazy-pack/gcp-setup-and-check.sh --project <Project ID>   # 直接指定 GCP 專案（不帶時會列出帳號下所有專案讓您選）

# 於本機執行第三階段（原始碼金鑰掃描 ＋ 20 題 AI 推薦與防套話紅隊測試）：
node lazy-pack/code-and-ai-audit.mjs --run-ai-eval                       # 不帶 --target：出「原始碼在哪裡」選單
node lazy-pack/code-and-ai-audit.mjs --source github --repo "<GitHub 網址>" --run-ai-eval   # 跳過選單，直接指定來源（cloud／github／local）
node lazy-pack/code-and-ai-audit.mjs --target "<藏家系統原始碼路徑>" --run-ai-eval         # 已知資料夾時
node lazy-pack/code-and-ai-audit.mjs --eval-only --url "<Cloud Run 網址>"                  # 20 題直接打真實線上網站（只考題、不掃原始碼）
```

**補充說明：**

- **專案選單**：第一、二階段不帶 `--project` 時，腳本會列出這個 Google 帳號下的所有 GCP 專案讓您選，並順便找出藏家推薦系統的 Cloud Run 網址記在 `reports/.lazy-pack-state.env`。
- **原始碼三種來源**（第三階段不帶 `--target` 時的選單）：`[A]` 雲端（Cloud Build 上傳的原始碼，找不到會引導從 Google AI Studio 下載）、`[B]` GitHub 網址 clone、`[C]` 搜尋本機「下載」與「桌面」的資料夾與 ZIP。抓下來的放 `reports/sources/`。`--target` 不能指到 Lazy Pack 自己。
- **20 題測試打哪裡**：依序是 `--url` → 第一階段記下的網址 → 本機模擬回應（`--mock` 可強制模擬）。用記下的網址前會先問 y/N，不能互動時一律模擬。網站要登入時，把 token 放環境變數 `LAZY_PACK_API_TOKEN`。
- **⚠️ 線上端點格式是假設的**：預設 `POST /api/recommend`、回 `{ recommendations, cc_list, blocked, message }`。真實系統的路徑與格式請先問開發者；路徑不同用 `--api-path <路徑>`（Git Bash 裡寫 `v2/rec`，不加開頭斜線）。
